## EM3 definition and unresolved memory boundaries

Section IV.1 (PDF IV A, p.9) describes an event of probability p at a pair
measurement, with complete two-qubit depolarization and an outcome flip in
half of the events. The original cited definition is unambiguous:
arXiv:2108.10457v2, Table 1, p.4, `ParityMeas(P1,P2,p)` uses a uniform draw
from `{I,X,Y,Z}^2 x {flip,no flip}` conditioned on the event. The Pauli is
applied **after** the measurement. Thus there are 32 equally likely draws,
including `(II,no flip)`; each draw has unconditional probability `p/32`.
The readout flip and data Pauli belong to the **same elementary event**.
Independent `DEPOLARIZE2(p)` and `MXX(p)`/`MZZ(p)` would give a different
fault set and different probabilities.

Table 2 of that cited paper also includes idle, initialization, single-qubit
measurement, and single-qubit Clifford noise through its EM3 gate set.
Stairway explicitly explains the pair-measurement event, but does not give a
gate-by-gate finite-memory start/end recipe or explicitly enumerate which
of these additional boundary/idle channels were used. Section VI.3.1's
Bell-reference experiment determines protected logicals; it does not itself
specify a Z/X memory initialization and termination circuit. Boundary
noise, burn-in, and the selected initial time slice remain unresolved for
an exact reproduction of the reported DEM distance. No alternative model
or boundary convention was chosen during this stopped audit.

## Read-only driver audit for when definitions become available

- Load the undecomposed full DEM through `problem.load_dem_problem`.
- `collapse_time` groups solely by the first two detector coordinates.
  Both detector class and type must be encoded there; the fourth coordinate
  alone does not distinguish collapsed rows. `fold_time` additionally uses
  `int(t) % period`.
- `project_rows` currently supports disjoint XOR groups, not overlapping
  arbitrary GF(2) maps. These projections are certified relaxations.
  `window_problem` is a mechanism restriction, giving verified upper bounds.
- `search.distance(..., k_table=2, cover=True, labelfree=True,
  time_limit=seconds, start=lower_bound, on_run=callback, rank=...,
  anchors=...)` exposes threshold records. Only an exhausted threshold with
  no witness raises the lower bound to `K+1`; a timeout does not.
- `symmetry.from_row_perms` can reject duplicate detector syndromes with
  different logical labels; log the result and fall back if needed.
- Search time limits exclude table construction. Estimate allocations before
  invoking a large label-free table to respect the local 2 GB ceiling.

**Existing shared replay limitation, left unchanged:**
`cdist/replay.py:MEASURE` excludes `MPP`, `MXX`, `MYY`, and `MZZ`.
`_noiseless` consequently retains their probability arguments. A local
probe on Stim 1.15.0 confirmed retained `[0.125]` arguments for `MXX`,
`MZZ`, and `MPP`. A future driver must explicitly remove pair-measurement
noise in a position-preserving replay copy or use an exactly equivalent
representation with noiseless measurement instructions. Also inspect
joint data/readout explanations: the present `replay` records classical
flips only in its branch for faults with no Pauli entries. A correlated
EM3 location carrying both fields needs correct handling. No shared file
