## Independent symbolic derivation

Write `tXA[i]`, `tXB[j]`, `tZA[i]`, `tZB[j]` for the times of the four kinds of monomial coupling. Here ZA denotes `A_i^T` on the right half and ZB denotes `B_j^T` on the left half, so X and Z always address opposite halves.

An X ancilla at cell `s` and a Z ancilla at cell `s+a_i+b_j` have two possible directed paths through data: XA_i followed by ZB_j on the left, and XB_j followed by ZA_i on the right. Their unwanted ancilla-to-ancilla action cancels precisely when

```
(tXA[i] < tZB[j]) == (tXB[j] < tZA[i])
```

for every pair `(i,j)`. This is a polynomial-independent sufficient condition. Checking sums of coinciding displacements modulo `(3,7)` gives exactly the same survivors for the printed 42-qubit polynomial.

To enumerate, **infer** that the four A monomials appear in increasing index order within the X schedule, and likewise the four B monomials. Enumerate the 70 possible interleavings of these two subsequences. For each, permute all four ZA couplings over the X-A time slots and all four ZB couplings over the X-B time slots. There are `70 * 24 * 24 = 40,320` candidates. Applying the 16 comparisons above leaves **212** schedules:

| X half pattern | Survivors |
| --- | ---: |
| LLRRRRLL | 96 |
| LRLRRLRL | 2 |
| LRRLLRRL | 8 |
| RLLRRLLR | 8 |
| RLRLLRLR | 2 |
| RRLLLLRR | 96 |

Table 2 belongs to this enumeration. In zero-based indexing its A time slots are `(0,2,5,7)`, ZA permutation is `(3,2,1,0)`, and ZB permutation is `(3,1,2,0)`. The middle entries B2/B3 are correct under the symbolic condition; reversing them also produces a valid schedule.

The fixed internal X subsequences are an inferred grammar convention, **not an explicit statement found in STAR**. The count 212 reproduces the claim under that convention. Allowing independent A/B relabeling of the internal X subsequences would produce `212 * 24^2 = 122,112` polynomial-independent raw schedules. It is therefore necessary to say whether schedules are counted with fixed monomial labels or up to label permutations. The paper's omitted grammar prevents proving that this inference is precisely its search space.

## Idle channels and the existing mirror family

Each monomial displacement is a bijection of the torus. In every layer all X ancillas couple bijectively to one data half and all Z ancillas couple bijectively to the other. Every one of the `4*ell*m` physical qubits participates in a CNOT in each entangling layer. Consequently the stated entangling-layer idle rule adds **zero channels** to this eight-layer family, and `noise="full"` and `noise="noidle"` must agree exactly if all other operations are unchanged.

`papers/sdbb_parallel.py` uses a palindromic X half pattern and makes Z equal to the reversed X order with halves exchanged. This always satisfies the comparison condition. The 42-qubit order file is `R0,L2,L1,R1,R3,L3,L0,R2`, with half pattern `RLLRRLLR`. Canonically relabeling A and B independently by their X occurrence order puts this order into one of the eight survivors with that half pattern. Without canonical relabeling, inclusion in the fixed-X-subsequence enumeration depends on the physical monomial dictionary.

The independent matrix comparison proves that STAR 42 does **not** have the same check matrices as the existing `selfdual_bb.py` 42 instance up to qubit/check relabeling: each vertex of their X-check intersection graphs lies in 45 and 39 triangles respectively. Thus the existing 42 mirror circuit cannot be transported to STAR by this kind of relabeling; the conditional requested comparison is inapplicable. This is a project result, not an assertion extracted from STAR; `tests/test_star.py` checks the invariant and `results/papers3/star/reconstruction.json` records the evidence. It does not address equivalence after arbitrary stabilizer-generator changes.

For 66 and 78 the matrices do match. Send the old torus cell `(x,y)` to STAR `(-x,x+y)`, the left data cell to `(-x+1,x+y+2)`, and the right data cell to `(-x-1,x+y-2)`, with coordinates reduced modulo `(3,m)`. The module and tests verify every X/Z row under these permutations, and transport all eight gate times of the saved mirror circuits unchanged.

## Open reconstruction assumptions

1. `Bi=Ai^T` is the natural self-dual index convention but is not printed. The clean-order condition holds for arbitrary B label assignments; determinism alone does not establish the chosen B dictionary.
2. Preparation in a basis is a basis reset followed by the stated depolarizing channel. The paper does not specify an additional noisy H in the preparation of X eigenstates.
3. Six memory rounds are requested by the task; III.A uses `r=3d` for its Monte Carlo memory experiment. These are different boundary experiments.
4. The requested 20/192 histogram cannot be assumed from the successful 212 correctness count; it still requires independent fault-distance searches.

## Supplementary 18-round memory check

The literal Table 2 circuit with the natural `Bi=Ai^T` assumption has exact circuit distance **6 in both bases at 18 rounds**, compared with the paper's stated 5. This rules out replacing the requested six rounds with III.A's `r=3d` memory duration as an explanation of the discrepancy, for this reconstruction. It does not resolve the omitted B-index dictionary.

Both searches use the full fault model, an undecomposed DEM, exact CSS sector reduction, and all 20 surviving translation symmetries. Each has 84 physical qubits, eight CNOT layers/cycle, 756 detectors and six observables. The Z circuit has 43,134 raw DEM mechanisms; X has 43,176. The full sector has 399 rows and 5,334 columns in each basis. Weight-five search exhausts, and a weight-six witness passes both DEM checking and physical Stim replay.
