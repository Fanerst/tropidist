## 1. Codes

### 1.1 Common properties (all rows)

- Family: weight-8 self-dual bivariate bicycle codes on twisted tori, n <= 200.
- Check weight: 8 for every X check and every Z check (four monomials of f on sublattice v1 plus four monomials of g on sublattice v2).
- **[derived]** Each qubit is in 4 X checks and 4 Z checks; there are n/2 X checks and n/2 Z checks; H_X = H_Z (see section 2.3).
- Selection rule (main text, "Search" section): for each even n the authors keep the code with the largest k d^2 / n; among ties they present the one with the most local stabilisers. So the tables list one code per n, not all codes found.
- Footnote 1 says only k > 4 cases are reported, since k = 2 and k = 4 are already achieved by the toric code and the colour code. Note this conflicts with the first row, [[16,4,4]], which has k = 4.

### 1.2 How d was determined

- Table 1 caption: "Code distances are computed exactly using the integer programming method of Refs. [31, 10]."
- Main text ("Search" section) repeats this: for candidates with k > 0 the distance is computed with the integer-programming method of the same two references.
- Ref. [31] = Landahl, Anderson, Rice, "Fault-tolerant quantum computing with color codes", arXiv:1108.5738 (2011). Ref. [10] = Bravyi, Cross, Gambetta, Maslov, Rall, Yoder, Nature 627, 778 (2024).
- So every d in the tables is claimed as an **exact** value from integer programming. No row is marked as a bound or estimate. No solver is named (no Gurobi / CPLEX / QDistRnd mention). No analytic proof of any d is given.
- Only a single d is quoted per code. **[derived]** Since H_X = H_Z, d_X = d_Z.
- These are code (data-qubit) distances only; nothing circuit-level.

## 2. Construction data

### 2.1 Conventions section ("Algebraic-geometric methods"), formulas exact

Setting (paraphrased): honeycomb lattice, one qubit on each vertex, two vertices v1 and v2 per unit cell. Pauli operators are written as 4-component column vectors over the Laurent polynomial ring; the upper two components are the X parts on (v1, v2) and the lower two are the Z parts on (v1, v2).

Eq. (1):

```
X_{v1} = [1, 0 | 0, 0]^T    Z_{v1} = [0, 0 | 1, 0]^T
X_{v2} = [0, 1 | 0, 0]^T    Z_{v2} = [0, 0 | 0, 1]^T
```

Translation by (n, m) lattice units = multiplication by `x^{n}y^{m}` (n, m integers); the x, y directions are those drawn in the top-left panel of Fig. 1. Products of Paulis are sums of vectors, so the Pauli algebra is a module over

Eq. (2): `R = \mathbb{Z}_2[x^{\pm 1}, y^{\pm 1}]`

A translation-invariant CSS code is given by two polynomials f, g in R:

Eq. (3):

```
S_X = [ f(x,y), g(x,y) | 0, 0 ]^T
S_Z = [ 0, 0 | \overline{g(x,y)}, \overline{f(x,y)} ]^T
```

where the overline is the antipode map `x^{n}y^{m} -> x^{-n}y^{-m}`. The stabiliser group is generated by all lattice translations of S_X and S_Z.

Logical dimension formulas:

Eq. (4): `k_max = 2 dim( Z_2[x^{±1},y^{±1}] / <f, g> )`

Eq. (5), for a twisted torus with `a1 = (0, α)` and `a2 = (β, γ)`:

`k = 2 dim( Z_2[x^{±1},y^{±1}] / < f(x,y), g(x,y), y^{α} - 1, x^{β}y^{γ} - 1 > )`

Topological-order condition (paraphrased): satisfied when f and g are coprime.

### 2.2 Twisted-torus boundary conditions

- A basis vector (p, q) imposes the relation `x^{p}y^{q} = 1`. This is fixed by Eq. (5) and by the Fig. 1 caption, which states that basis vectors (0,8) and (4,4) mean the boundary conditions `y^{8}=1` and `x^{4}y^{4}=1`.
- Search parametrisation (main text): for each even n, all decompositions `n = 2 l × m`, with `a1 = (0, m)` and `a2 = (l, q)`, `0 <= q < m`; boundary conditions `y^{m} - 1` and `x^{l}y^{q} - 1`.
- So for a table row with a1 = (0, α), a2 = (β, γ): relations `y^{α} = 1`, `x^{β}y^{γ} = 1`; the translation group has α·β elements and n = 2·α·β.
- The paper says exponent pairs (a,b), (c,d) were enumerated inside the parallelogram spanned by a1 and a2. The tables nevertheless print negative exponents; **[derived]** these are equivalent representatives modulo the lattice, presumably chosen to display the most local form. It makes no difference to the check matrices.

### 2.3 Self-duality

- Definition used (main text, "Search" section): `\overline{f} = g`. Eq. (14): `f(x,y) = 1 + x + x^{a}y^{b} + x^{c}y^{d}` with `g(x,y) := \overline{f(x,y)}`. The tables therefore list only f.
- Stated consequence (paraphrased): the condition makes each stabiliser inversion-symmetric about the plaquette centre, which guarantees that X and Z stabilisers commute.
- Fig. 1 caption (paraphrased): the X stabiliser is the product of X on all red (f) and blue (g) vertices, and the Z stabiliser is the same pattern with Z.
- **[derived]** Substituting g = f-bar into Eq. (3): `S_Z = [0, 0 | \overline{g}, \overline{f}] = [0, 0 | f, g]`, i.e. exactly the support of S_X. Hence **H_X = H_Z** as matrices under a fixed qubit labelling. The paper never writes "H_X = H_Z" or any explicit parity-check matrix; it works only in the polynomial formalism. The Discussion does contrast its codes with a [[64,8,8]] code that is self-dual only up to column permutation, which supports the fixed-labelling reading.
- Doubly-even: all checks have weight 8 (divisible by 4), which the paper uses for transversal S.

### 2.5 Rebuild recipe **[derived]**

For a row with f = sum of four monomials `x^{e1}y^{e2}`, a1 = (0, α), a2 = (β, γ):

1. Group G = Z^2 / <(0,α), (β,γ)>, order α·β. Canonical representative of (p, q): `t = floor(p / β)`, `i = p - t·β`, `j = (q - t·γ) mod α`, giving (i, j) with 0 <= i < β, 0 <= j < α.
2. Qubits: (v1, s) and (v2, s) for s in G; n = 2·α·β.
3. A = sum over the exponents e of f of the translation (permutation) matrix by e on G. The matrix of g = f-bar is A^T.
4. H_X = H_Z = [ A | A^T ] (α·β rows each). This is the standard BB form H_X = [A | B], H_Z = [B^T | A^T] with B = A^T.
5. Checks to assert: the four monomials of f are distinct in G (row weight 8, column weight 4); H H^T = 0 mod 2; k = n - 2·rank(H) equals the table value.

### 2.7 Other construction statements

- Theorem 1 (weight 6): `f = 1+x^{a}y^{b}+x^{c}y^{d}`, `g = 1+x^{-a}y^{-b}+x^{-c}y^{-d}`, `Δ := ad - bc`, `k_max = 4|Δ|`, attained on the twisted torus with basis vectors `(3a, 3b)` and `(c+a, d+b)`.
- Discussion: the general weight-8 ansatz is Eq. (16) `f = 1+x^{a}y^{b}+x^{c}y^{d}+x^{e}y^{f}`; the search was restricted to Eq. (14) for cost and because many cases map to it by a unimodular monomial change of variables. Only for n = 64 was the general ansatz also scanned, with no improvement in kd^2/n. So for n other than 64 the tables are optimal only within the Eq. (14) ansatz.
- The [[64,8,8]] stabiliser `1+x+y+y^{-1}` is identified with "modified color code C" of Ref. [35] (Liang, Xu, Iosue, Chen, PRX Quantum 5, 030328 (2024)) and is described as the most local weight-8 construction.
