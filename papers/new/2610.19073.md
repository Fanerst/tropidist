# arXiv:2610.19073: "A modular quantum computer based on Cornucopia codes"

Notes for the distance check, read from https://arxiv.org/html/2610.19073v2 on 2026-10-20 (all three parts of the
HTML text).  Authors: Z. Lu, W. Li, Y. Ma, H. Yan, B. Wang, Y. Ma, Z.-Z. Sun, D.-L. Deng.  Paraphrased; no
computation is described in the paper beyond what is listed here.

## Codes and distances that the paper uses

- One memory code: the Cornucopia code [[2844,1426,18]] (q = 79) of arXiv:2608.02773.  Its distance is taken
  from that paper ("certified in ref. [40]"); the paper itself does not recompute it.  It recomputes k from the
  ranks (rank H_X = rank H_Z = 709).
- Comparison: 119 modules of the two-gross [[288,12,18]] bicycle code (cited), and a distance-18 rotated surface
  code patch as the magic-state source (assumed).

## Distance claims for the logical operations

All are lower bounds that follow from theorems, not from computations of distances:

- Theorem 2 (graph surgery): the merged code has distance at least d if the ancilla graph has a complete cycle
  basis and expansion h2 >= 1.  The proof uses only that every nontrivial logical of the input code has weight
  >= d.  This is the standard gauging-measurement argument (Cheeger constant at least one).
- The expansion is certified through lambda_2 > 2 of the graph Laplacian (h >= lambda_2 / 2), proved with an
  integer (exact) certificate; for the fixed extractor, for each of 40 Fourier blocks of size 54 (numerically
  lambda_2 = 2.501).
- Proposition 1 (matching bridges): two such gadgets joined by b >= d bridge edges keep distance >= d; with
  b = d = 18 the merged distance is exactly 18 (X on the bridge qubits is a logical operator).
- Direct sums of compatible gadgets (parallel surgery) keep distance d.

"Verified exactly" (Extended Data Tabs. 3 and 4, Tab. S4, all 25,578 bridged classes) means: the merged code is
assembled and its commutation, rank over F2 (k' = 1425 or 2851), measured operator, row and column weights
(w_max <= 16, Delta_max <= 9 or 12) and the spectral certificates are checked.  No merged-code distance is
computed.  Merged codes have up to 24,174 data qubits (2,844 code + 21,330 ancilla) and 22,753 checks.

The circuit-level (fault) distance of the surgery protocols is explicitly not established (it depends on the
syndrome-extraction schedule).  The per-qubit logical error rate 2.6e-16 at p = 1e-3 is the extrapolation of
arXiv:2608.02773 (Tab. 1), which uses the fit p^(d/2) with the code distance d = 18.
