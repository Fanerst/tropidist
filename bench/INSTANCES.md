Mitten-300 records only the lower bound certified by the named result files. The Cornucopia-1044 code-capacity paper claim starts as `unknown`; a local exact result is used only when its certificate is present and its input hashes match the rebuilt matrices.

The `surface` family (`surface_d3`, `surface_d5`, ..., `surface_d25`) uses Stim's `surface_code:rotated_memory_z` generator with `distance = rounds = d`. It is the rotated surface-code memory family used by Webster, Jacob, and Higgott (arXiv:2603.22532, section 5.5 / table 20), generated independently rather than imported from their circuit files. All four noise arguments are set to 0.001: `after_clifford_depolarization`, `before_round_data_depolarization`, `before_measure_flip_probability`, and `after_reset_flip_probability`. At d = 11, with the same generator and noise arguments, our count is 24483 and theirs is 24485; our raw mechanism count uses the undecomposed DEM with `flatten_loops=True`. The remaining difference of two mechanisms is unexplained because their circuit file is unavailable; the benchmark does not tune noise to match it. Flattening a default looped DEM after generation instead counts 26803 error instructions, so these counting paths must not be mixed.

Surface detector coordinates are rewritten to `(check, 0, round, type)` after loops and coordinate shifts are flattened. Check indices are stable within each measurement-basis type, read from the circuit, with type 0 for X checks and type 3 for Z checks. The generated gates, noise, detector targets, and observable are retained. Rotation by 180 degrees is the sole geometric symmetry candidate, expressed by the same check-index permutation in both type spaces; reflections do not preserve the check types. The exporter retains the candidate only where it is an actual symmetry of the variant. `bench.stim_families.graphlike_distance` computes exact `sector` and `collapsed` truth separately using shortest paths in the graph doubled by observable parity, after verifying every column has at most two detectors and there is one observable. The verified exact sector reduction supplies the same truth for `full`.

The `stim_color` family (`color_d3`, `color_d5`, `color_d7`, `color_d9`, `color_d11`) uses Stim's unchanged `color_code:memory_xyz` generator with `distance = rounds = d` and the same four noise arguments at 0.001. Its changing measurement bases do not form separate CSS memory sectors, so it exports only `full`. Ground truth is read from `results/bench_truth/<name>.json` using `certified_lower_bound` and `certified_upper_bound`; matching certified bounds give exact truth, otherwise a certified lower bound is recorded. When the file is absent, truth is normally `unknown` and the instance remains available.

In the table, `n` counts data qubits. Physical qubit counts for the Stim families count the distinct used qubit indices, including measurement qubits. Stim's `Circuit.num_qubits` instead counts up to the highest index, including gaps; at surface d = 11 there are 241 physical qubits but an indexed count of 274.
